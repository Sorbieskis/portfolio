Architecture: Tiered QA Validation Framework

Systems Engineer | Deimonas Suchanka

From Ad-Hoc to Standardized QA

Architected a new validation framework to move from basic functional checks to objective, data-driven quality assurance, addressing senior management's goal for improved knowledge capture.

the problem

The existing quality checks (FAT/IAT) verified basic functionality but consistently missed subtle performance variations. This lack of a standardized, data-driven process created three core business problems: a lack of objective data for quality assurance, no formal process for capturing engineering knowledge, and a clear gap in aligning with industry quality standards like ISO 9001.

methodology

  1. 1. Foundational Analysis

    Leveraged the findings from the Pekos system analysis as a catalyst to demonstrate the need for a more rigorous validation process.

  2. 2. Workflow Modeling

    Analyzed the existing ad-hoc workflow and designed a new, structured process with clear decision points and escalation paths.

  3. 3. Framework Architecture

    Designed a tiered (Level 1-3) system to efficiently handle everything from routine QA checks to deep-dive root cause analysis for complex issues.

  4. 4. Metric & Procedure Definition

    Defined specific, data-driven performance metrics (e.g., Consistency Index) and developed a lean, actionable SOP for Level 1 validation.

framework architecture

  • Level 1: Routine Validation

    A lean, standardized procedure for commissioning engineers to perform data-driven pass/fail checks on all machines, providing objective QA evidence.

  • Level 2: Targeted Diagnosis

    A focused investigation, triggered by a Level 1 failure, to quickly diagnose the issue and determine a corrective action (e.g., parameter tuning, mechanical fix).

  • Level 3: Deep-Dive RCA

    A full, systematic root cause analysis involving a cross-functional team for complex, systemic issues, modeled on the Pekos investigation.

deliverables

QA Validation Framework A formal proposal outlining the tiered (L1-L3) framework, stakeholder impact, key metrics, and implementation plan.
Level 1 Test Procedure (VTP) A lean, single-page Standard Operating Procedure (SOP) for conducting routine performance validation in the workshop.
Standardized Data Template An Excel template for data collection and automatic calculation of the Consistency Index (CI) metric during Level 1 tests.
