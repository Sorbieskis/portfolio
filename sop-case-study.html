Platform: Project Unidoc - Enterprise Documentation Platform

Systems Engineer | Deimonas Suchanka

Production-Deployed Django/Wagtail CMS Platform

Identified a critical business bottleneck, proposed a solution to leadership, and independently architected and delivered a complete system now in production.

the problem

The company's strategic shift toward highly configurable products created a documentation scalability crisis. The existing ad-hoc process, based on scattered Word files, was a high-risk liability.

This process could not support structured technical documentation requirements, which impacted delivery schedules and created a significant operational risk.

technical solution

  • Architecture & Backend Development

    Architected a complete Django application using the Wagtail CMS. Built 15+ database models, a custom snippet system for reusable content, and a flexible service layer architecture with 34 custom StreamField blocks for modular content.

  • PDF Generation Pipeline

    Integrated WeasyPrint to create an automated PDF generation pipeline. The system includes custom styling, automatic figure numbering, alphabetical index generation, and dynamic headers/footers based on document metadata.

  • Testing & Quality Assurance

    Authored 114 automated tests using pytest to ensure system reliability, achieving 42% code coverage with a sub-3-second execution time. Configured Ruff for code linting and pre-commit hooks to maintain code quality.

  • Production Deployment

    Successfully deployed the platform to a Windows Server environment. This included configuring an IIS web server, integrating with an SQL Server database, and building an automated rsync deployment pipeline with safety checks.

technical stack

Backend Python 3.11, Django 5.2, Wagtail 7.1 CMS
Database SQL Server with Django ORM, 15+ models
Frontend Wagtail StreamField custom blocks (34 types), custom admin interface & templates
Testing pytest (114 tests), Ruff linting, pre-commit hooks
Deployment Windows Server, IIS, automated rsync pipeline, WeasyPrint PDF generation
